# План доработок

## 1. Правила автозакрытия авто (vehicle)

**Сейчас:** при `Готово` авто закрывается, если ровно 26 палет ИЛИ ровно 21500 кг. Похоже из-за прошлых правок 14п/14000 кг тоже закрывается (нужно подтвердить в логе при тесте).

**Будет:**
- Авто закрывается автоматически при `Готово`, только если выполнено хоть одно:
  - всего палет в авто ≥ 26, ИЛИ
  - всего вес в авто в диапазоне 21000–21500 кг
- Иначе — авто остаётся `open` и отображается всем staff-менеджерам в новом разделе **«Авто на догрузку»** (на странице «Поставки» / отдельная вкладка).

Файл: `src/routes/_authenticated/shipments/$id.products.tsx` (`syncVehicleStateForShipment`).

## 2. Раздел «Авто на догрузку» (open vehicles)

Добавить в `/shipments` секцию/вкладку «На догрузку», где показываются все `vehicles.status='open'` с >0 загрузки. Карточка авто показывает:
- свободные палеты (26 − загружено)
- свободный вес (21500 − загружено)
- список товаров: товар · сорт · палеты · вес · **ответственный менеджер**
- кнопка «Догрузить» — создаёт новую поставку текущего менеджера, привязанную к этому `vehicle_id`, и открывает редактор товаров
- кнопка «Закрыть авто» — доступна любому менеджеру, у которого в этом авто есть товар, только если в авто есть загрузка

После закрытия авто продолжает быть видно (раздел «Закрытые авто» или фильтр), с тем же составом, без возможности редактировать.

## 4. Распределение — индикация чужой загрузки

В `/distribution` (нераспределённые авто):
- Сейчас показывается общий «нераспределено» по авто.
- Будет — для каждого менеджера:
  - До распределения своих палет: `Xсвоё/Yчужое` где `X` красный (своё нераспределено), `Y` серый (чужое, не моё дело).
  - После распределения своих: только `Xсвоё` зелёным (всё своё распределено), без чужих.
  - Если распределено частично: `Aкрасное / Yсерое` остаток + желтый бейдж «дораспределить N» (логика как сейчас по цветам).

Файл: `src/routes/_authenticated/distribution.tsx`.

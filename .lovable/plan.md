# Подключение проекта к GitHub и скачивание ZIP

## Что нужно сделать
1. Открыть проект в Lovable на компьютере.
2. Запустить подключение GitHub через меню **Plus (+) → GitHub → Connect project**.
3. Авторизовать GitHub App, выбрать аккаунт или организацию и создать репозиторий.
4. После синхронизации открыть созданный репозиторий на GitHub.
5. Скачать код через **Code → Download ZIP**.

## Инструкция после подключения
- На GitHub открыть страницу репозитория.
- Нажать зелёную кнопку **Code**.
- Выбрать **Download ZIP**.
- Распаковать архив локально.

## Важно
- Подключение GitHub выполняется пользователем в интерфейсе Lovable; в текущем наборе инструментов нет действия, которое может подтвердить OAuth-доступ или создать репозиторий вместо пользователя.
- Синхронизация двусторонняя: изменения из Lovable и GitHub могут передаваться между проектом и репозиторием.
- На мобильном устройстве путь начинается в **Chat mode → Plus (+) → GitHub**; скачивание ZIP удобнее выполнить на компьютере или через приложение GitHub.
- Никакие файлы проекта, база данных, настройки доступа или production-данные не изменяются до завершения подключения пользователем.
